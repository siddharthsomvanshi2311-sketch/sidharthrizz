# siddharthis.cool - Portfolio Website

A modern, interactive portfolio website built with Next.js, Tailwind CSS, and Framer Motion.

## Getting Started

### Prerequisites
- Node.js 18+ and npm/yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/siddharthsomvanshi2311-sketch/sidharthrizz.git
cd sidharthrizz

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

## Project Structure

```

├── app/
│   ├── page.tsx          # Home page
│   ├── layout.tsx        # Root layout
│   ├── about/
│   ├── projects/
│   ├── blog/
│   └── contact/
├── components/           # Reusable components
├── public/               # Static assets
└── lib/                  # Utility functions
```

## Customization

1. Update your personal information
2. Add your projects
3. Customize colors in `tailwind.config.js`
4. Replace images in `public/` folder

## Deployment

Deploy on Vercel (recommended):

```bash
npm install -g vercel
vercel
```
